# 完整範例：《西遊記》三打白骨精 → 3 分鐘動畫（公有領域）

使用者貼上第二十七回開頭約 2,000 字的原文，要求做成 3 分鐘、16:9、中文配音的日式動畫。

**畫風錨點**（整部片固定）
```
日式動畫風格，劇場版等級作畫，細膩清晰的線稿，賽璐璐上色，多層次光影，頭髮與衣服自然飄動，電影級調色，淺景深。
```

**人物_悟空_常服**
```
日式動畫風格，劇場版等級作畫，細膩清晰的線稿，賽璐璐上色，多層次光影。全身人物立繪：精瘦結實的猴王，金褐色毛髮，銳利的火焰金色眼睛，額頭戴著金色頭箍，黃色短衣外罩紅金色短甲背心，腰圍虎皮裙，赤腳。正面站立面向鏡頭，雙腳著地，從頭到腳完整入鏡，神情桀驁、嘴角帶著痞笑。乾淨的白色背景，均勻光線，沒有文字，沒有浮水印。
```

### 改編大綱（3 分鐘）

| 時段 | 內容 |
|---|---|
| 0:00–0:30 | **鉤子**：一隻蒼白的手撥開草叢，一雙紫色的眼睛盯著山道上的師徒四人。（妖怪先露面，但不揭露她會變成誰） |
| 0:30–1:00 | 唐僧喊餓，悟空用金箍棒畫圈，叮囑大家不要出圈，駕雲離去 |
| 1:00–1:45 | 村姑提著飯罐走來，八戒很殷勤，唐僧被說動，走出了圈 |
| 1:45–2:40 | **高潮**（55 秒，約佔片長的 1/3）：悟空回來，火眼金睛識破，一棒打下，白煙中一具假屍倒地 |
| 2:40–3:00 | 唐僧震怒念咒，悟空抱頭倒地；草叢中的紫眼冷笑（留給下一集） |

**語音方針**：不用旁白；台詞是中文；主要說話者是悟空、唐僧、八戒。

## 第二輪：③ 每分鐘細綱（節錄 1:45–2:40）

```
### 1:45–2:40
【下午轉黃昏・山道旁大石邊的空地・晴，太陽在悟空背後形成逆光】
具體內容：悟空踏著金白色的雲落在空地邊，雙手捧著一缽齋飯，笑著喊師父。
他的笑容在看見村姑時凝住，雙眼燃起金色火焰，瞳孔裡映出一具骷髏。
他把缽往旁邊一放，抽出鐵棍。八戒張開雙臂擋在村姑前面，悟空一腳把他踢開，
躍起一棒劈下。村姑碎成一團白煙，一具假屍倒在地上，飯罐摔破，爬出蛆蟲。
唐僧踉蹌後退，臉色發白。
【本分鐘看點】
1. 悟空帥氣落地、捧著缽的笑容（反差的前置）
2. 火眼金睛的大特寫：瞳孔映出骷髏
3. 八戒擋人被踢飛（笑點）
4. 逆光躍起、一棒劈下（高潮畫面）
5. 白煙炸開、假屍倒地、飯罐裡爬出蛆蟲（揭露）
6. 唐僧的驚恐反應
【本分鐘對白】
- 悟空（畫面內，短句）：「師父，齋來了！」——目的：反差的前置
- 八戒（畫面內）：「猴哥住手！」——目的：笑點，阻擋
- 悟空（畫面內，短句）：「妖怪，看棍！」——目的：高潮的爆點
- 唐僧（聲畫分離，長句）：「悟空！你怎能傷害無辜的女子！」——目的：衝突，接到下一段
```
